# StayGeo - Booking Management System

## Description
ჯავშნების მართვის ლოკალური სისტემა (Console Application). პროექტი საშუალებას გაძლევთ დაამატოთ, ნახოთ, წაშალოთ ჯავშნები, დააექსპორტოთ მონაცემები CSV-ში და შექმნათ ანალიტიკური გრაფიკები.

## Features
- ახალი ჯავშნის დამატება და მართვა
- მონაცემთა შენახვა JSON ფაილში
- მონაცემთა ექსპორტი CSV ფაილში (Pandas)
- ვიზუალური ანალიტიკის გენერირება (Matplotlib)
- ავტომატური ტესტები (Pytest)

## Installation
გაუშვით შემდეგი ბრძანება საჭირო ბიბლიოთეკების დასაყენებლად:
pip install -r requirements.txt

## How to Run
პროგრამის გასაშვებად:
python main.py

ტესტების გასაშვებად:
pytest
